# 🍜 บันทึกรายรับ-รายจ่าย ร้านขายอาหาร

แอปเว็บสำหรับบันทึกรายรับ-รายจ่ายของร้านขายอาหาร พร้อมติดตามเป้าหมายเงินคงเหลือ ใช้งานได้ทั้งบนมือถือและคอมพิวเตอร์ ติดตั้งเป็นแอป (PWA) ได้ ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูลใดๆ

🔗 **ใช้งานได้ที่:** https://mdt3ch99.github.io/food-tracker/

---

## ✨ ฟีเจอร์

- บันทึกรายรับ/รายจ่ายแยกตามหมวดหมู่ (วัตถุดิบ, ค่าเช่า, ยอดขาย, เงินกู้ยืม ฯลฯ)
- แดชบอร์ดสรุปเงินคงเหลือ ยอดขาย รายจ่ายรวม แบบเรียลไทม์
- ตั้งเป้าหมายเงินคงเหลือ พร้อมวงแหวนแสดงความคืบหน้า (%)
- ค้นหา / กรองตามประเภท / กรองตามช่วงวันที่ (วันนี้, 7 วัน, เดือนนี้)
- สรุปยอดตามช่วงวันที่ที่เลือกเอง
- แก้ไข / ลบรายการ พร้อมปุ่ม **เลิกทำ (Undo)** ย้อนกลับได้หลายรายการ
- สำรอง/กู้คืนข้อมูล: ดาวน์โหลด JSON, คัดลอกข้อความ, ส่งออก CSV, นำเข้า JSON
- ติดตั้งเป็นแอปบนมือถือได้ (PWA) และใช้งานออฟไลน์ได้ผ่าน Service Worker
- รองรับภาษาไทยเต็มรูปแบบ (ปฏิทินพุทธศักราช)

## 📁 โครงสร้างไฟล์

ไฟล์ทั้งหมดต้องอยู่ใน **โฟลเดอร์เดียวกัน** (root ของ repo) ห้ามแยกใส่ subfolder เพราะไฟล์อ้างอิงกันด้วย relative path:

```
food-tracker/
├── index.html                  # ตัวแอปหลัก (HTML + CSS + JS ในไฟล์เดียว)
├── food-tracker.webmanifest    # ข้อมูลสำหรับติดตั้งเป็น PWA
├── food-tracker-icon.svg       # ไอคอนแอป
├── sw.js                       # Service Worker สำหรับใช้งานออฟไลน์
└── README.md
```

---

## 🚀 วิธี Deploy (ผ่าน GitHub Pages)

1. อัปโหลดไฟล์ทั้งหมดข้างต้นไว้ที่ root ของ repo (branch `main`)
2. ไปที่ **Settings > Pages**
3. ใต้ "Build and deployment" เลือก Source เป็น **Deploy from a branch**
4. เลือก Branch เป็น `main` และโฟลเดอร์เป็น `/ (root)` แล้วกด **Save**
5. รอ 1-2 นาที เว็บไซต์จะพร้อมใช้งานที่ `https://<username>.github.io/<repo-name>/`

> **หมายเหตุ:** Service Worker (`sw.js`) จะทำงานเฉพาะเมื่อเข้าผ่าน `https://` หรือ `http://localhost` เท่านั้น หากเปิดไฟล์ตรงจาก disk (`file://`) ฟีเจอร์ออฟไลน์/ติดตั้งแอปจะใช้งานไม่ได้ แต่แอปหลักยังใช้งานได้ปกติ

## 💾 การเก็บข้อมูล

ข้อมูลทั้งหมดเก็บไว้ใน **`localStorage`** ของเบราว์เซอร์บนอุปกรณ์นั้นๆ เท่านั้น

- ไม่มีการส่งข้อมูลออกไปเซิร์ฟเวอร์ใดๆ ทั้งสิ้น ข้อมูลเป็นส่วนตัว 100%
- ข้อมูล**ไม่ sync ข้ามอุปกรณ์หรือเบราว์เซอร์**โดยอัตโนมัติ
- หากต้องการย้ายข้อมูลไปอีกเครื่อง ให้ใช้ปุ่ม **"ดาวน์โหลด JSON"** จากเครื่องเดิม แล้วนำไฟล์ไป **"นำเข้า JSON"** ในเครื่องปลายทาง
- ล้างข้อมูลเบราว์เซอร์ (clear browsing data) จะทำให้ข้อมูลในแอปหายไปด้วย — ควรสำรองข้อมูลเป็นประจำ
